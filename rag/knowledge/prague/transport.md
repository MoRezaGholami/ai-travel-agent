# پراگ — حمل‌ونقل

## از فرودگاه تا شهر
- **فرودگاه Václav Havel (PRG)**: اتوبوس + مترو یا تاکسی/ترانسفر. معمولاً ۳۵–۵۰ دقیقه.

## جابه‌جایی داخل شهر
- **تراموا**: بهترین دوست گردشگر در پراگ.
- **مترو**: سه خط؛ برای مسافت بلندتر مفید است.
- **پیاده‌روی**: مرکز فشرده است و بهترین روش دیدن جاذبه‌ها.
- **قایق ولتاوا**: بیشتر تفریحی.

## نکات کاربردی
- بلیت ۳۰ دقیقه / ۹۰ دقیقه / ۲۴ ساعته بخرید و اعتبارسنجی کنید.
- از تاکسی‌های بدون قیمت مشخص کنار جاذبه‌ها پرهیز کنید.
- دوچرخه در مرکز سنگفرش‌شده همیشه راحت نیست.
